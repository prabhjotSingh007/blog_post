200	OK	Request completed successfully.
201	Created	A new resource was created successfully.
202	Accepted	Request accepted for processing (often asynchronous).
204	No Content	Request succeeded, but no response body is returned.

400	Bad Request	Invalid request syntax or missing/invalid parameters.

401	Unauthorized	Authentication is required or the provided credentials are invalid.
403	Forbidden	User is authenticated but does not have permission.
404	Not Found	The requested resource does not exist.
405	Method Not Allowed	The HTTP method is not supported for the endpoint.
409	Conflict	Request conflicts with the current state of the resource (e.g., duplicate email).
415	Unsupported Media Type	The request body format is not supported (e.g., XML instead of JSON).
422	Unprocessable Entity	Request syntax is valid, but validation failed (e.g., invalid email format).
429	Too Many Requests	Client has exceeded the rate limit.
500	Internal Server Error	An unexpected error occurred on the server.
501	Not Implemented	The requested functionality is not implemented.
502	Bad Gateway	Server received an invalid response from an upstream server.
503	Service Unavailable	Server is temporarily unavailable (maintenance or overload).
504	Gateway Timeout	Upstream server took too long to respond.
